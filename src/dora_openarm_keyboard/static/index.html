How to use
  1. Wait for the header to say connected, then click this page once so it has keyboard focus.
  2. Choose which arm the motion keys drive: 1 left, 2 right, 3 both together.
  3. Hold a motion key to move and release it to stop — WASDRF translate, IKJLUO rotate, G/H close/open the gripper and Q/E raise/lower the lifter. Hold Shift for quarter speed while placing precisely.
  4. Esc disables teleoperation and stops everything held; press it again to enable. Leaving this page releases every key, so the robot never keeps moving unwatched.

Nothing moves? Check that the header says connected, click the page, and press Esc in case teleoperation is disabled. If your keyboard uses an input method editor, switch it to direct alphanumeric input — composed keystrokes never reach this page.
